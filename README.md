# Palinal Bolivia — página temporal

Página estática de “Próximamente” para Palinal Bolivia, distribuida por
Inversiones y Desarrollos 3D (ID3D).

## Publicación

El sitio se publica con GitHub Pages desde la raíz de la rama `main`:

- Repositorio: <https://github.com/cesarszv/palinal-landing-building>
- URL predeterminada: <https://cesarszv.github.io/palinal-landing-building/>
- Dominio personalizado: <https://palinal.bo/>

`CNAME` conserva la asociación del dominio personalizado y `.nojekyll` evita
que GitHub Pages procese el sitio con Jekyll.

## Contenido publicado

- `index.html`
- `support.js`
- `assets/`

Los archivos de referencia, exportaciones y material archivado son locales y
se excluyen mediante `.gitignore`.
